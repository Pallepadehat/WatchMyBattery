# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be welcoming, assume good intent, and keep discussions about the work. Harassment and personal attacks are not tolerated.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer privately through GitHub (for example by opening a [private security advisory](../../security/advisories/new) marked "Conduct", or via the contact details on the maintainer's profile). Reports are handled confidentially.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this code, and may temporarily or permanently ban contributors for behaviour they consider harmful.
